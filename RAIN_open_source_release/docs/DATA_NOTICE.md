# Data provenance and licensing

The MIT license applies to original software only. Third-party datasets,
monitoring records, remote-sensing products, and materials derived from cited
studies remain subject to the terms of their original providers.

The PM2.5 experiment uses the benchmark split described in the accompanying
article and derived from monitoring data released by the China National
Environmental Monitoring Centre. The mineral prospectivity experiment uses the
dataset and folds described in the accompanying article and its cited source
study. These files are included solely to support scientific reproducibility.

Reuse and redistribution of the datasets must comply with the original terms.
Users should cite the original data providers and source studies. If a provider
requires access through an official repository, obtain the data there and use
`SHA256SUMS.txt` to verify that locally reconstructed inputs match this release.
